# ScoreGame

Telegram Mini App для футбольных прогнозов. Игроки каждый день предсказывают счёт трёх матчей, используют джокеры и бусты, соревнуются в лигах, собирают звёзды, мячи, кейсы и достижения, проходят сезонные задания и долгосрочные прогнозы на сезон.

Продакшен: [scoregameee.online](https://scoregameee.online) · бот [@scoregameee_Bot](https://t.me/scoregameee_Bot)

## Стек

Next.js 16 + React 19 (статический экспорт) на фронте, четыре Cloudflare Workers на бэкенде, Cloudflare D1 (SQLite) как единая база. Всё на TypeScript.

## Архитектура

| Пакет | Роль |
|---|---|
| `web/` | Mini App UI и админ-панель, статический экспорт в `web/out` |
| `front-worker/` | Раздаёт статику, проксирует `/api/*` в api-worker через service binding |
| `api-worker/` | Вся бизнес-логика: роуты, доступ к D1, скоринг, экономика, cron, админка |
| `bot-worker/` | Telegram-бот: вебхук, напоминания, дневные сводки, привязка лиг к каналам |

Поток запроса: `Telegram Mini App → front-worker → api-worker → D1`. Воркеры общаются между собой через service bindings, наружу открыт только front-worker и вебхук бота.

Точки входа: [web/app/page.tsx](web/app/page.tsx), [api-worker/src/index.ts](api-worker/src/index.ts), [bot-worker/src/index.ts](bot-worker/src/index.ts), [front-worker/src/index.ts](front-worker/src/index.ts). Схема базы — миграции в [api-worker/migrations/](api-worker/migrations/), применяются по порядку.

Подробный разбор устройства проекта — в [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md).

## Как игра устроена

Матчи дня подтягиваются из внешних провайдеров (football-data.org, AllSports через RapidAPI), дедуплицируются и три лучших выбираются автоматически. Прогноз оценивается по схеме 5 / 3 / 2 / 0 — точный счёт, разница мячей, исход, мимо. После финализации результатов пересчитываются агрегаты за день, неделю, месяц и сезон, проверяются достижения и задания, начисляются награды. Ручная корректировка счёта администратором всегда имеет приоритет над данными провайдера.

Дневной сброс и вся логика расписаний считаются по московскому времени.

## Статус

Проект в продакшене и активно развивается. Репозиторий опубликован как демонстрация кода: часть внутренних документов (экономические расчёты, отчёты по нагрузке, операционные заметки) в публичную версию не входит.
